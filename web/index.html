第 1 步 · 授权

在 Cloudflare 边缘，
搭建你的免费代理节点

5 分钟一键完成 VLESS 节点部署与 IP 优选。

在 Cloudflare Dashboard 创建 Custom Token，需要以下权限：
  • Zone : Zone : Read
  • Zone : DNS : Edit
  • Account : Workers Scripts : Edit
  • Account : Workers KV Storage : Edit
  • Account : Cloudflare Pages : Edit

权限检查

缺少以下权限，部署会在第 3 步失败。请到 Cloudflare Dashboard 编辑 Token 并勾选：
